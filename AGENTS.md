# Expo docs: match the SDK the app is on

Rally is pinned to **Expo SDK 54** for the 1.0 launch (owner decision 11/20/26; the SDK 57
upgrade is planned for after launch). Read the SDK 54 docs before writing Expo code:
https://docs.expo.dev/versions/v54.0.0/

APIs in newer SDK docs (v55+) may not exist in SDK 54. When the app moves to SDK 57, change
this link to https://docs.expo.dev/versions/v57.0.0/.

Cloud sessions can't reach docs.expo.dev; read the same pages from Expo's GitHub repo
instead: https://github.com/expo/expo/tree/main/docs/pages/versions/v54.0.0
