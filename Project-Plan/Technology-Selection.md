# Unnamed StartUp

## Project Overview 
This project will be an app for college organizations to easily schedule and plan events, and also collaborate with other organizations on campus.

## Technology Choices 

### Language 
- **Typescript/JavaScript**
- **SQL**

### Framework 
- **Frontend Mobile:** React Native

- **Primary Database Ecosystem:** Supabase (Managed PostgreSQL)
- **Real-Time Data Engine:** Supabase Realtime / Websockets

-
- **Build Tool:**
